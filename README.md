# 블록시티

블록으로 나만의 도시를 짓고, 여러 도구로 부숴 보는 3D 물리 브라우저 게임입니다. 실제 장소가 아닌 가상 도시만 씁니다.

## 하는 법

- 땅은 36×36칸이고, 도로가 가로·세로 두 줄씩 있습니다.
- **짓기**: 집·아파트·빌딩·탑·나무를 골라 땅을 누르면 놓입니다. 방향 버튼으로 돌리고, 빼기로 지웁니다. 랜덤 도시로 한 번에 채울 수 있습니다.
- **랜덤 학교**: 가상의 학교 캠퍼스(본관·별관·시계탑·체육관·운동장·조회대·담장·나무)를 매번 다른 배치와 방향으로 짓습니다. 실제 학교를 본뜨지 않습니다.
- **부수기** (PC에서는 숫자 키 1~6으로도 바꿈)
  - 폭탄: 누른 곳이 터집니다.
  - 배트: 누른 곳을 지나가도록 거대한 배트를 휘두릅니다. 크기 ×0.5~×3. 한 번에 30블록 넘게 치면 홈런.
  - 레이저: 화면을 끌어 선을 그으면 하늘이 어두워진 뒤 빔이 그 선을 따라가며 태웁니다.
  - 운석: 하늘에서 떨어져 크게 터집니다.
  - 지진: 누른 곳이 진원입니다. 규모 4.0~10.0. 4~5는 잔해만 흔들리고, 6~7은 위층이, 8.5 이상은 건물이 통째로 무너집니다.
  - 핵폭탄: 하늘에서 떨어져 넓은 범위를 날리고 버섯구름이 오릅니다.
- **밤**(N 키): 창문에 불이 켜집니다.
- 도구를 바꿔 가며 빠르게 부수면 점수 배율이 오르고, 건물을 무너뜨리면 보너스를 받습니다.
- 화면 조작: 끌기는 돌리기, 오른쪽 끌기·두 손가락은 옮기기, 휠·두 손가락 벌리기는 확대입니다.

## 만든 방법

- `index.html` 한 파일입니다. 3D는 three.js r160, 물리는 Rapier 0.19.1(둘 다 jsDelivr CDN), 소리는 Web Audio로 합성합니다.
- 건물은 1×1×1 블록을 쌓은 것입니다. 서 있는 블록은 고정 충돌체이고, 부서지면 움직이는 강체로 바뀌어 부딪히고 굴러 쌓입니다.
- 아래 블록이 빠지면 그 위 블록이 차례로 떨어집니다.
- 움직이는 조각이 1,700개를 넘으면 오래 멈춰 있던 잔해부터 치워 느려지지 않게 합니다.
- 지은 도시는 브라우저(localStorage)에 저장됩니다.
