# 블록시티

블록으로 나만의 도시를 짓고, 폭탄·운석·지진으로 부숴 보는 3D 브라우저 게임입니다. 실제 장소가 아닌 가상 도시만 씁니다.

## 하는 법

- **짓기**: 집·아파트·빌딩·탑·나무를 골라 땅을 누르면 놓입니다. 방향 버튼으로 돌리고, 빼기로 지웁니다. 랜덤 도시로 한 번에 채울 수 있습니다.
- **부수기**: 폭탄(누른 곳 폭발), 운석(하늘에서 떨어짐), 지진(3초 흔들림). PC에서는 숫자 키 1~3으로도 바꿉니다.
- 아래가 부서지면 위층이 무너지고, 빠르게 날아간 조각은 옆 건물도 부숩니다.
- 화면 조작: 끌기는 돌리기, 오른쪽 끌기·두 손가락은 옮기기, 휠·두 손가락 벌리기는 확대입니다.

## 만든 방법

- `index.html` 한 파일입니다. 3D는 three.js r160(CDN), 소리는 Web Audio로 합성합니다.
- 건물은 1×1×1 블록을 쌓은 것이고, 블록은 인스턴스 메시 두 개(창문 벽 / 무늬 없음)로 한 번에 그립니다.
- 물리 엔진은 쓰지 않습니다. 중력과 바닥 높이표로 직접 계산하고, 멈춘 조각은 그 칸의 높이를 올려 잔해 더미가 쌓입니다.
- 지은 도시는 브라우저(localStorage)에 저장됩니다.
